---
title: Actualizar los prefijos de una puerta de enlace local
description: Cambia los rangos de la red on-premise o la IP pública del dispositivo VPN sin recrear la conexión.
shell: azurecli
category: Virtual Network Gateway
tags: [vpn, local-gateway, local-network-gateway, actualizar, prefijos, rutas]
template: "az network local-gateway update --resource-group <resourceGroup> --name <localGatewayName> --local-address-prefixes <addressPrefixes>"
parameters:
  - name: resourceGroup
    label: Grupo de recursos
    type: string
    required: true
    placeholder: mi-grupo-recursos
  - name: localGatewayName
    label: Nombre de la puerta de enlace local
    type: string
    required: true
    placeholder: mi-local-gateway
  - name: addressPrefixes
    label: Prefijos de la red local (separados por espacio)
    type: string
    required: true
    placeholder: 192.168.0.0/16 10.50.0.0/16
---

La lista que indicas reemplaza a la anterior, no se suma: incluye siempre todos los rangos que quieras mantener.

Para cambiar la IP del dispositivo usa `--gateway-ip-address <nueva-ip>`. En túneles con rutas estáticas el cambio de prefijos renegocia los selectores de tráfico y puede cortar el túnel unos segundos.
