---
title: Ver el estado de una conexión VPN
description: Consulta si el túnel está conectado y cuántos bytes ha transferido desde que se estableció.
shell: azurecli
category: Virtual Network Gateway
tags: [vpn, gateway, conexion, estado, status, diagnostico, consulta]
template: "az network vpn-connection show --resource-group <resourceGroup> --name <connectionName> --query \"{Nombre:name, Estado:connectionStatus, BytesEntrada:ingressBytesTransferred, BytesSalida:egressBytesTransferred, IpRemota:localNetworkGateway2.gatewayIpAddress}\" --output <output>"
parameters:
  - name: resourceGroup
    label: Grupo de recursos
    type: string
    required: true
    placeholder: mi-grupo-recursos
  - name: connectionName
    label: Nombre de la conexión
    type: string
    required: true
    placeholder: conexion-onprem
  - name: output
    label: Formato de salida
    type: enum
    required: false
    default: table
    options: [table, json, jsonc, tsv, yaml]
---

`connectionStatus` toma los valores `Connected`, `Connecting`, `NotConnected` y `Unknown`.

Si se queda en `Connecting` o `NotConnected`, revisa en este orden: la clave compartida en los dos extremos, la IP pública declarada en el local network gateway, los prefijos anunciados y las reglas del firewall local (UDP 500 y 4500, y el protocolo ESP).
