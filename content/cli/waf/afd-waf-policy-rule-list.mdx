---
title: Listar reglas personalizadas de una política WAF de Front Door
description: Muestra las reglas personalizadas de una política WAF de Front Door, incluidas las de límite de tasa.
shell: azurecli
category: WAF
tags: [waf, front-door, afd, reglas, custom-rule, rate-limit, consulta]
template: "az network front-door waf-policy rule list --resource-group <resourceGroup> --policy-name <policyName> --output <output>"
parameters:
  - name: resourceGroup
    label: Grupo de recursos
    type: string
    required: true
    placeholder: mi-grupo-recursos
  - name: policyName
    label: Nombre de la política
    type: string
    required: true
    placeholder: mi-waf-frontdoor
  - name: output
    label: Formato de salida
    type: enum
    required: false
    default: json
    options: [json, jsonc, table, tsv, yaml]
---

Devuelve las reglas con su prioridad, tipo (`MatchRule` o `RateLimitRule`), acción y estado.

Las condiciones de coincidencia no vienen en esta salida; para verlas hay que pedir la regla concreta con `az network front-door waf-policy rule show --resource-group <rg> --policy-name <politica> --name <regla>`, o bajar el JSON completo de la política.

Requiere la extensión de Front Door (`az extension add --name front-door`).
