---
title: Listar reglas gestionadas de una política WAF de Front Door
description: Muestra los conjuntos de reglas gestionadas (DRS, Bot Manager) activos en una política WAF de Front Door.
shell: azurecli
category: WAF
tags: [waf, front-door, afd, reglas-gestionadas, drs, bot-manager, consulta]
template: "az network front-door waf-policy managed-rules list --resource-group <resourceGroup> --policy-name <policyName> --output <output>"
parameters:
  - name: resourceGroup
    label: Grupo de recursos
    type: string
    required: true
    placeholder: mi-grupo-recursos
  - name: policyName
    label: Nombre de la política
    type: string
    required: true
    placeholder: mi-waf-frontdoor
  - name: output
    label: Formato de salida
    type: enum
    required: false
    default: json
    options: [json, jsonc, table, tsv, yaml]
---

Devuelve el tipo y la versión de cada conjunto aplicado: normalmente `Microsoft_DefaultRuleSet` y `Microsoft_BotManagerRuleSet`.

Los valores de `--type` que piden los comandos de exclusiones y overrides salen de aquí, así que este es el comando que hay que ejecutar primero.

Para ver el catálogo de reglas disponibles con su descripción, el equivalente al catálogo de Application Gateway es `az network front-door waf-policy managed-rule-definition list --output table`.

Requiere la extensión de Front Door (`az extension add --name front-door`).
