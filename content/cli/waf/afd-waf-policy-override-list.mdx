---
title: Listar reglas modificadas de una política WAF de Front Door
description: Muestra los overrides aplicados sobre las reglas de un conjunto gestionado en una política WAF de Front Door.
shell: azurecli
category: WAF
tags: [waf, front-door, afd, override, reglas-gestionadas, deshabilitadas, consulta]
template: "az network front-door waf-policy managed-rules override list --resource-group <resourceGroup> --policy-name <policyName> --type <ruleSetType> --output <output>"
parameters:
  - name: resourceGroup
    label: Grupo de recursos
    type: string
    required: true
    placeholder: mi-grupo-recursos
  - name: policyName
    label: Nombre de la política
    type: string
    required: true
    placeholder: mi-waf-frontdoor
  - name: ruleSetType
    label: Conjunto de reglas
    description: Tipo del conjunto gestionado, tal como lo devuelve managed-rules list.
    type: enum
    required: true
    default: Microsoft_DefaultRuleSet
    options: [Microsoft_DefaultRuleSet, DefaultRuleSet, Microsoft_BotManagerRuleSet]
  - name: output
    label: Formato de salida
    type: enum
    required: false
    default: json
    options: [json, jsonc, table, tsv, yaml]
---

Equivalente en Front Door a los `ruleGroupOverrides` de Application Gateway: las reglas que alguien deshabilitó o a las que cambió la acción.

Vale la misma advertencia: **solo salen las reglas tocadas**. Las que siguen con su comportamiento por defecto están activas y no aparecen aquí. El catálogo completo con el que cruzarlo es `az network front-door waf-policy managed-rule-definition list`.

Requiere la extensión de Front Door (`az extension add --name front-door`).
