  - name: output

El punto de partida cuando llegas a un entorno que no conoces: cruza todas las suscripciones visibles de una sola vez, sin ir grupo por grupo.

Requiere la extensión de Resource Graph, que se instala con `az extension add --name resource-graph`. En Cloud Shell suele venir ya instalada.

Los IDs que devuelve se pueden pasar directamente a `az resource show --ids` para exportar la configuración completa de cada política.

Para limitarlo a una suscripción añade `--subscriptions <id-suscripcion>`. Y si quieres ver también el modo de cada política sin bajar el JSON completo, cambia el `project` por `project name, resourceGroup, modo = properties.policySettings.mode, estado = properties.policySettings.state`.
