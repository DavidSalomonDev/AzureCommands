Vista cruda de lo que el kernel ve. Útil cuando acabas de adjuntar un disco y `lsblk` todavía no lo muestra.

No viene instalado de serie: `sudo apt-get install -y lsscsi` o `sudo dnf install -y lsscsi`. Si no puedes instalarlo, `ls -l /dev/disk/azure/` da información parecida.
