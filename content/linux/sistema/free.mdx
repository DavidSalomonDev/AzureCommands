Mira la columna **available**, no **free**: Linux usa toda la RAM que sobra como caché de disco y eso es correcto, no un problema.

Muchas imágenes de Azure no traen swap configurada. Si hace falta, se habilita sobre el disco temporal (`/mnt`) vía `cloud-init`, nunca sobre el disco de sistema.
