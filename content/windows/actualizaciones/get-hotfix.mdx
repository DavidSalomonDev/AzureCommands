  - name: count
    label: Cuántos KBs mostrar
    type: number
    required: false

La consulta de referencia para responder "¿está parcheado este servidor?". Ordenado por fecha, las primeras líneas dicen cuándo se aplicó el último ciclo de parches.

`Get-HotFix` solo ve lo que viene del motor de Windows Update / CBS: las actualizaciones de Defender y las de Store no aparecen. Para un KB concreto: `Get-HotFix -Id KB5034123`.
