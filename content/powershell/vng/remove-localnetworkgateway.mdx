---
title: Eliminar una puerta de enlace local
description: Borra un local network gateway que ya no se usa.
shell: powershell
category: Virtual Network Gateway
tags: [vpn, local-gateway, local-network-gateway, eliminar, borrar]
template: "Remove-AzLocalNetworkGateway -ResourceGroupName <resourceGroup> -Name <localGatewayName> -Force"
parameters:
  - name: resourceGroup
    label: Grupo de recursos
    type: string
    required: true
    placeholder: mi-grupo-recursos
  - name: localGatewayName
    label: Nombre de la puerta de enlace local
    type: string
    required: true
    placeholder: mi-local-gateway
---

Falla mientras exista una conexión que lo referencie: elimina antes la conexión con `Remove-AzVirtualNetworkGatewayConnection`. Quita `-Force` si prefieres que pida confirmación.
