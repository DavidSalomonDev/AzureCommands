```bash
az deployment group create --resource-group rg-backup-prod --template-file rsv-protect-vm.json
```

El despliegue va sobre el grupo de recursos **del almacén**, no el de la VM: el elemento protegido
es un recurso hijo del almacén. La VM sí puede estar en otro grupo —se indica en
`vmResourceGroup`—, pero tiene que estar en la misma región que el almacén.

El nombre largo del recurso es el identificador que Azure Backup espera y se arma solo a partir de
los parámetros: `iaasvmcontainer;iaasvmcontainerv2;<grupo>;<vm>`. No hace falta tocarlo.

Volver a desplegar la plantilla sobre una VM ya protegida sólo cambia su política, así que sirve
también para moverla de política. Para respaldar varias VMs, repite el recurso con `copy`:

```json
"copy": { "name": "vms", "count": "[length(parameters('vmNames'))]" }
```
