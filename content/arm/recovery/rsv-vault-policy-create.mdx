```bash
az deployment group create --resource-group rg-backup-prod --template-file rsv-vault-policy.json
```

El almacén y la política se crean juntos; después se protegen las VMs con la plantilla
*Proteger una VM con Azure Backup*, que apunta a este `vaultName` y `policyName`.

De `backupTime` sólo cuenta la hora (`06:00:00`): la fecha es relleno que exige el formato. La
política guarda un respaldo diario y, además, el del domingo durante las semanas indicadas.

Lo que esta plantilla deja fuera a propósito:

- **La redundancia del almacenamiento** (LRS/GRS/ZRS) se define antes del primer respaldo, con
  `az backup vault backup-properties set --backup-storage-redundancy GeoRedundant`. Por defecto queda en GRS.
- **El almacén no se puede eliminar** mientras tenga elementos protegidos, y el borrado temporal
  (soft delete) retiene los puntos 14 días.
