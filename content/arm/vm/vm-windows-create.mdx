Guarda el JSON como `vm-windows.json` y despliégalo sobre un grupo de recursos ya creado:

```bash
az deployment group create --resource-group rg-app-prod --template-file vm-windows.json
```

`adminPassword` es el único parámetro sin valor por defecto: la CLI lo pide al desplegar, así
la contraseña no queda escrita en el archivo. Para automatizarlo, pásala como
`--parameters adminPassword=...` o, mejor, con `@Microsoft.KeyVault(...)` en un archivo de parámetros.

La VM se conecta a una subred que ya existe y **no lleva IP pública**: entra por Bastion, VPN o
ExpressRoute. Trusted Launch exige una imagen de generación 2 (las SKU `-azure-edition`, `-g2` y
`-gensecond` lo son) y un tamaño compatible; si usas una imagen Gen1, quita el bloque
`securityProfile`. Añade `"zones": ["1"]` al recurso de la VM para fijarla en una zona de
disponibilidad.
