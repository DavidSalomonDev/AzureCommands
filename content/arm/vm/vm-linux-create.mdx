```bash
az deployment group create --resource-group rg-app-prod --template-file vm-linux.json
```

Sólo entra por clave SSH: `disablePasswordAuthentication` está en `true` y no hay parámetro de
contraseña. Si no tienes clave, créala con `ssh-keygen -t ed25519` y pega el contenido de
`~/.ssh/id_ed25519.pub`.

Combinaciones de imagen más usadas (`publisher` / `offer` / `sku`), todas generación 2 y por tanto
compatibles con Trusted Launch:

- `Canonical` / `ubuntu-24_04-lts` / `server`
- `Canonical` / `0001-com-ubuntu-server-jammy` / `22_04-lts-gen2`
- `RedHat` / `RHEL` / `9-lvm-gen2`
- `SUSE` / `sles-15-sp6` / `gen2`

Consulta las vigentes con `az vm image list --publisher Canonical --all --output table`. La VM no
lleva IP pública: se entra por Bastion, VPN o ExpressRoute.
