```bash
az deployment group create --resource-group rg-red-prod --template-file lng-connection.json
```

`sharedKey` no tiene valor por defecto: se pide al desplegar y no queda escrita en el archivo.
Tiene que ser idéntica a la configurada en el dispositivo local, que ahí suele llamarse
*pre-shared key*.

Los rangos de `localAddressPrefixes` no pueden solaparse con el espacio de direcciones de la VNet.
Para varios rangos, escribe el arreglo completo en un archivo de parámetros:

```json
"localAddressPrefixes": { "value": ["192.168.0.0/16", "172.16.0.0/12"] }
```

Con BGP activado hay que añadir `bgpSettings` al Local Network Gateway (ASN y dirección del peer) y
la puerta de enlace de Azure también debe tenerlo habilitado; sin BGP, el enrutamiento sale de los
rangos declarados aquí y actualizarlos es la vía normal para publicar una red nueva al sitio local.

El túnel sólo se levanta cuando el dispositivo local tiene la configuración espejo. Revisa el
estado con `az network vpn-connection show --name cnx-monterrey --resource-group rg-red-prod --query connectionStatus`.
